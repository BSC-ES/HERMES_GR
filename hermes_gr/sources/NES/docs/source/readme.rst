Introduction
============

About
============

NES (NetCDF for Earth Science) is the Python I/O library used by SNES, the framework that implements the data post-processing pipelines at the Earth Sciences department, to read and write netCDF files.

How to install
============

Use the following command to install the library:

::

   pip install nes

For installation troubleshooting, read the
`FAQ <https://github.com/BSC-ES/NES/wiki/FAQ>`_.

How to run
============

For installation guidance, usage instructions, tutorials, and CLI documentation,
see the `GitHub wiki <https://github.com/BSC-ES/NES/wiki>`_.
